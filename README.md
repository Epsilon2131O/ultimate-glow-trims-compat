# Ultimate Glow Trims Compat

Makes [Moog's Glow Up](https://modrinth.com/mod/moogs-glow-up) glowing and resonant effects work everywhere they don't on their own.

## Features
- Glowing and resonant trims on **horse and wolf armor** (Animal Armor Trims, Netherite Horse Armor, More Wolf Armors)
- Glowing banner layers on **mounts** (More Banner Features)
- Glowing and resonant trims on **tools and weapons** (Trimmable Tools), with a tooltip line
- All of the above with **Trim's - Color Splash** extra colorways
- Makes **netherite horse armor** and **More Wolf Armors** armors trimmable
- Gold-free netherite horse and wolf armor, matching vanilla netherite, so trims don't clash with the gold lines
- Works with **Sodium** and **Iris** shaders

## Client and server
- **Glowing effects, textures and colors** are client-side
- **Making netherite horse armor and More Wolf Armors trimmable** is server-side data: install on the server too if you want those armors to accept trims.


## Notes
- First-person shader glow on tools is tuned for Complementary Reimagined/Unbound and Euphoria Patches. I have not tested other shaders but they may work.

## Requirements
NeoForge 1.21.1 and Moog's Glow Up. Everything else is optional; each feature turns on when its mod is installed.
